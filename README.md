# QTKD Thực hành Phase 2

Repository thực hành xây dựng hệ thống Quản trị kinh doanh bằng ASP.NET Core Web API, Entity Framework Core và PostgreSQL. Solution được sử dụng xuyên suốt tuần 05–07.

## Báo cáo thực hành

[Tuần 05 — Xây dựng nền tảng QTKD](Week05_report/README.md)

Báo cáo trình bày các bước thực hiện, hướng dẫn cấu hình và chạy ứng dụng, mô hình dữ liệu, sơ đồ thành phần và ảnh minh chứng Postman, pgAdmin.
